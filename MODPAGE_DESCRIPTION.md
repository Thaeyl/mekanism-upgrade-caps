# Short Description

Configure Mekanism machine speed and energy upgrade caps beyond the default 8, with matching performance scaling, tooltip display, config file support, and in-game commands.

# Mod Page Description

Mekanism Upgrade Caps is a lightweight NeoForge add-on for Minecraft 1.21.1 that lets you configure how many Speed and Energy upgrades Mekanism machines can accept.

Unlike simple stack-size tweaks, this mod also updates the actual machine behavior: extra upgrades affect processing speed, energy usage, energy capacity, and the upgrade tooltip display. Caps can be changed through a config file or in-game commands.

Commands:

```text
/mekupgradecaps get
/mekupgradecaps set speed 64
/mekupgradecaps set energy 64
```

Requires Mekanism and NeoForge.
